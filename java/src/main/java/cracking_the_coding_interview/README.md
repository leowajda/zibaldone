Solutions to the problems in "Cracking the Coding Interview - 189 Programming Questions & Solutions". 

**I would advise against going through this book as it's almost a decade old and out of touch with today's interview standards.** <br>
Half of the book is a complete waste of time and if a chapter is missing from the repo, it can safely be skipped.
The chapters on basic data structures (such as arrays, strings, linked lists, etc.) make up good introductory material.
The problems related to bit manipulation and searching are noteworthy for their valuable insights and clear explanations. <br>
Interestingly, the author has (conveniently) decided to skip the time and space complexity analysis for most of the problems, particularly the ones of medium and hard difficulty.
